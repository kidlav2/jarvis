# Джарвис — домашний голосовой помощник

Говоришь «Привет, Джарвис» или «Hey Jarvis», задаёшь вопрос, он отвечает голосом. Работает на Windows и macOS.

- **Слух:** слово-пробуждение и распознавание речи работают на твоём компьютере. Пока не прозвучало имя, звук никуда не уходит.
- **Мозг:** на выбор Claude Code (подписка Claude), Cursor CLI (подписка Cursor), Codex (подписка ChatGPT) или **бесплатный ключ Groq**, если подписок нет.
- **Голос:** Edge TTS (бесплатно), ElevenLabs (живой голос с эмоциями, есть бесплатный тариф) или офлайн-голос Piper, если нет интернета.
- **Камера:** по просьбе «посмотри» делает один снимок и описывает, что видит. Без просьбы камера не включается.
- **Память:** запоминает то, что ты просишь запомнить. Хранится у тебя в `~/.jarvis-assistant/memory.md`.
- **Логи:** каждый вопрос записывается в `~/.jarvis-assistant/turns.jsonl`: что услышал, что ответил, сколько секунд это заняло и какие были ошибки. По ним видно, что улучшать.

## Что нужно

- Windows 10/11 или macOS (Apple Silicon или Intel).
- Python 3.12 с [python.org](https://www.python.org/downloads/). На Windows при установке поставь галочку **Add python.exe to PATH**.
- Микрофон и колонки. Камера по желанию.
- Один «мозг» на выбор:
  - **Claude Code:** `npm install -g @anthropic-ai/claude-code`, затем `claude` и вход в аккаунт.
  - **Cursor CLI:** на Windows в PowerShell `irm 'https://cursor.com/install?win32=true' | iex`, на Mac `curl https://cursor.com/install -fsS | bash`. Затем `cursor-agent login`.
  - **Codex:** `npm install -g @openai/codex`, затем `codex login`.
  - **Без подписки — Groq (бесплатно):** см. раздел ниже.

## Без подписки: бесплатный ключ Groq

1. Зайди на [console.groq.com](https://console.groq.com), войди через Google, открой **API Keys** и нажми **Create API Key**.
2. Создай рядом с `jarvis.py` файл `groq_key.txt` и вставь в него ключ. Никому его не показывай.
3. В `config.json` поставь:
   ```json
   "brain": "api",
   "stt": "groq"
   ```
   Одним ключом работают и мозг, и распознавание речи, поэтому Джарвис быстро отвечает даже на слабом ПК без видеокарты.

Модель Джарвис выбирает сам из тех, что Groq сейчас отдаёт бесплатно. У бесплатного ключа есть дневные лимиты (порядка сотен вопросов в день, точные числа смотри в консоли Groq в разделе Limits). Когда лимит кончится, Джарвис так и скажет. Камера в этом режиме не работает, она есть только с Claude.

Так же подключаются другие сервисы с OpenAI-совместимым API, достаточно поменять `api_url`:
- Gemini: `https://generativelanguage.googleapis.com/v1beta/openai`, ключ из Google AI Studio;
- Ollama на своём компьютере: `http://127.0.0.1:11434/v1`, ключ не нужен.

Учти: вопросы и распознанная речь уходят в выбранный сервис.

## Установка

**Windows:** правый клик по `install.ps1` → «Выполнить с помощью PowerShell».
**macOS:** в Терминале `bash install.sh`.

Установщик ставит зависимости, создаёт `config.json` и спрашивает, запускать ли Джарвиса автоматически при входе.

## Настройка (`config.json`)

| Поле | Что значит |
|---|---|
| `owner_name` | как Джарвис тебя называет |
| `city` | твой город, для погоды и времени |
| `brain` | `claude`, `cursor`, `codex` или `api` (Groq и другие) |
| `stt` | `local` — распознавание на компьютере; `groq` — быстрое облачное (нужен бесплатный ключ Groq в `groq_key.txt`), подходит для слабых ПК без видеокарты |
| `stt_model` | для `local`: `small` быстрее, `large-v3-turbo` точнее |
| `tts` | `edge` или `elevenlabs` (ключ кладётся в файл `eleven_key.txt` рядом с программой) |
| `camera` | `true` или `false` |

Ключи храни только в файлах `*_key.txt`. Они в `.gitignore` и никуда не публикуются.

## Проверка и запуск

```
python jarvis.py --test    # голос, мозг, камера, микрофон
python jarvis.py           # обычный режим
```

На Windows используй `.venv\Scripts\python.exe`, на Mac — `.venv/bin/python`.

## Как говорить

- «Привет, Джарвис» → он отвечает «Да?» и слушает.
- «Привет, Джарвис, какая завтра погода?» — можно сразу с вопросом.
- Пока он говорит, скажи «Hey Jarvis», и он замолчит и будет слушать.
- «Пока», «отбой», «до свидания» завершают разговор.

## Если что-то не так

- **Не слышит имя:** говори чётче и ближе к микрофону. «Hey Jarvis» срабатывает надёжнее всего.
- **Долго отвечает:** поставь `"stt": "groq"` или `"stt_model": "small"`.
- **Камера не снимает:** на Mac разреши Терминалу доступ к камере в настройках конфиденциальности. На Windows проверь `camera_index` (0, 1…).
- **Ошибки:** смотри `~/.jarvis-assistant/jarvis.log` и `turns.jsonl`.

Неофициальный проект, не связан с Anthropic, Cursor или OpenAI.
