# Изменения

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по [SemVer](https://semver.org/lang/ru/):
`MAJOR.MINOR.PATCH` — несовместимые изменения настроек / новые возможности / исправления.

## [1.2.0] — 2026-11-17

### Добавлено
- **Автообновление.** Раз в 6 часов Джарвис проверяет новую версию на GitHub, скачивает её и ставит между разговорами (не посреди ответа), потом перезапускается и говорит «Я обновился до версии …».
- Настройки (`config.json`), ключи и библиотеки при обновлении не трогаются. Старая версия сохраняется в `~/.jarvis-assistant/backup-<версия>`.
- Если новая версия не проходит проверку, она не ставится.
- `--update`: обновиться прямо сейчас. Выключить автообновление: `"auto_update": false`.

## [1.1.0] — 2026-11-17

### Добавлено
- Установка в один клик: `install.command` (macOS, двойной клик в Finder) и `install.cmd` (Windows).
- Удаление: `uninstall.sh` / `uninstall.cmd`.
- Пошаговая настройка `--setup`: имя, город, выбор мозга, ключи вводятся скрыто.
- Самопроверка `--doctor`: показывает, что не так и как исправить.
- Мозг `api`: бесплатный ключ Groq, а также Gemini, Ollama и другие OpenAI-совместимые сервисы. Модель выбирается автоматически.
- Выбор микрофона (`mic_device`), запись в лог при запуске в фоне (`--service`), `--version`.
- Инструкция для ИИ-агентов (`AGENTS.md`), лицензия MIT, автопроверка кода на GitHub.

### Изменено
- Автозапуск на Windows без чёрного окна консоли.
- Установщики сами находят или предлагают поставить Python 3.12.

## [1.0.0] — 2026-11-17

Первая публичная версия: слово-пробуждение («Hey Jarvis», «Привет, Джарвис»), распознавание речи, мозг на Claude Code / Cursor CLI / Codex, голос Edge / ElevenLabs / Piper, камера по команде, память, лог каждого вопроса.
