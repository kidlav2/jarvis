# Джарвис

**Домашний голосовой помощник для Windows и macOS.** Скажи «Привет, Джарвис», задай вопрос, и он ответит голосом.

[![check](https://github.com/kidlav2/jarvis/actions/workflows/check.yml/badge.svg)](https://github.com/kidlav2/jarvis/actions/workflows/check.yml)
![platform](https://img.shields.io/badge/platform-Windows%20%7C%20macOS-lightgrey)
![license](https://img.shields.io/badge/license-MIT-blue)

- **Слышит своё имя:** «Hey Jarvis», «Привет, Джарвис», «Слушай, Джарвис». Можно сразу с вопросом: «Привет, Джарвис, какая завтра погода?»
- **Умный мозг на выбор:** Claude, Cursor, ChatGPT (Codex) по твоей подписке или **бесплатно** через Groq.
- **Говорит по-русски:** бесплатный голос, живой голос ElevenLabs с эмоциями или офлайн-голос без интернета.
- **Смотрит по просьбе:** «посмотри, что у меня в руке» — делает один снимок камерой. Сама камера не включается.
- **Помнит:** то, что попросишь запомнить, хранится у тебя на компьютере.
- **Приватный:** пока не прозвучало имя, звук никуда не уходит.

## Установка

### Windows
1. Нажми зелёную кнопку **Code → Download ZIP** и распакуй архив.
2. Дважды кликни **`install.cmd`**.
   Если Windows покажет «Система Windows защитила ваш компьютер»: **Подробнее → Выполнить в любом случае**.
3. Отвечай на вопросы установщика. Python он поставит сам, если его нет.

### macOS
1. **Code → Download ZIP**, распакуй.
2. Правый клик по **`install.command`** → **Открыть** → **Открыть** (в первый раз macOS спрашивает про файлы из интернета).
3. Отвечай на вопросы установщика.

Установщик ставит всё нужное, спрашивает имя, город и мозг, проверяет компьютер и предлагает автозапуск при входе. Если распознавание речи выбрано на компьютере (`"stt": "local"`), при первом запуске скачается модель распознавания, около 1,5 ГБ. Запускать его можно повторно: он обновит программу и сохранит твои настройки.

> Можно попросить своего ИИ-агента (Claude Code, Cursor, Codex): «Установи Джарвиса из этой папки». Для агентов есть инструкция [AGENTS.md](AGENTS.md).

## Выбор мозга

| Мозг | Что нужно | Камера |
|---|---|---|
| `claude` | подписка Claude + [Claude Code](https://docs.anthropic.com/claude-code): `npm install -g @anthropic-ai/claude-code`, затем `claude` и вход | да |
| `cursor` | подписка Cursor + Cursor CLI: Windows `irm 'https://cursor.com/install?win32=true' \| iex`, Mac `curl https://cursor.com/install -fsS \| bash`, затем `cursor-agent login` | нет |
| `codex` | подписка ChatGPT + `npm install -g @openai/codex`, затем `codex login` | нет |
| `api` | **бесплатно:** ключ [Groq](https://console.groq.com) → API Keys → Create API Key | нет |

С Groq один ключ закрывает и мозг, и распознавание речи, поэтому Джарвис быстро отвечает даже на слабом ПК без видеокарты. У бесплатного ключа есть дневной лимит (сотни вопросов, точное число видно в консоли Groq). Когда лимит закончится, Джарвис так и скажет.

С `api` работают и другие сервисы, нужно только поменять `api_url`: Gemini (`https://generativelanguage.googleapis.com/v1beta/openai`, ключ из Google AI Studio) или локальная Ollama (`http://127.0.0.1:11434/v1`, без ключа).

## Как говорить

| Сказать | Что будет |
|---|---|
| «Привет, Джарвис» | «Да?» — и слушает |
| «Привет, Джарвис, включи…» / «…сколько времени?» | сразу отвечает |
| «Hey Jarvis», пока он говорит | замолкает и слушает |
| «Посмотри на меня» | снимок камерой и описание |
| «Запомни, что…» | запишет в память |
| «Пока», «отбой», «до свидания» | завершает разговор |

## Настройки

Всё лежит в `config.json`. Проще всего перенастроить, запустив установщик ещё раз.

| Поле | Значение |
|---|---|
| `owner_name`, `city` | как тебя называть и твой город |
| `brain` | `claude`, `cursor`, `codex`, `api` |
| `brain_model` | модель (пусто — по умолчанию / автовыбор) |
| `stt` | `local` (на компьютере), `groq` (облако, быстро), `server` |
| `stt_model` | для `local`: `small` быстрее, `large-v3-turbo` точнее |
| `tts` | `edge` (бесплатно) или `elevenlabs` |
| `camera`, `camera_index` | камера вкл/выкл и её номер |
| `mic_device` | часть названия микрофона, например `"BRIO"` (пусто — системный) |
| `wake_threshold` | чувствительность к «Hey Jarvis», 0.3–0.7 |
| `auto_update` | автообновление, по умолчанию включено |

Ключи хранятся только в файлах `groq_key.txt`, `eleven_key.txt` рядом с программой. В репозиторий они не попадают.

## Если что-то не так

Сначала запусти проверку, она скажет, что исправить:

```
Windows:  .venv\Scripts\python.exe jarvis.py --doctor
macOS:    .venv/bin/python jarvis.py --doctor
```

`--test` проверяет голос, мозг, камеру и микрофон по-настоящему.

| Проблема | Решение |
|---|---|
| Не слышит имя | выбери микрофон в `mic_device`, говори «Hey Jarvis» чётко |
| Долго отвечает | `"stt": "groq"` или `"stt_model": "small"` |
| Молчит в ответ | смотри `errors` в логе; Edge иногда сбоит, тогда включается офлайн-голос |
| Камера не снимает | macOS: разреши камеру для Терминала/Python в «Конфиденциальность и безопасность»; Windows: `camera_index` 1 |

Логи лежат в `~/.jarvis-assistant/`: `jarvis.log` — общий, `turns.jsonl` — по одному вопросу на строку (что услышал, что ответил, сколько секунд, ошибки). Если просишь помощи, приложи их.

Удаление: `uninstall.cmd` (Windows) или `bash uninstall.sh` (macOS).

## Обновления

Джарвис обновляется сам: раз в 6 часов проверяет новую версию, ставит её между разговорами и говорит «Я обновился до версии …». Твои настройки и ключи остаются. Обновиться сразу: `jarvis.py --update`. Выключить: `"auto_update": false` в `config.json`.

История изменений в [CHANGELOG.md](CHANGELOG.md), все версии в [Releases](https://github.com/kidlav2/jarvis/releases).
